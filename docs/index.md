# Gestión de Escuelas Deportivas

Documentación del proyecto de una plataforma web para administrar escuelas deportivas. La primera implementación es **Rojas Fútbol Club**.

## Estado actual

| Ítem | Estado |
|---|---|
| Visión y alcance v1.0 | Borrador acordado |
| Requisitos funcionales y no funcionales | Borrador |
| Reglas de negocio | Cuotas, pagos, recibos y preinscripciones definidas; resto pendiente |
| Modelo de datos | Pendiente |
| Arquitectura | Stack propuesto, a formalizar |
| Implementación | No iniciada |

## Documentos vivos

## Origen

Este proyecto continúa el trabajo iniciado como sitio web institucional de Rojas Fútbol Club ([relevamiento](06-sitio-publico/rojas-fc.md)). El alcance se amplió a un sistema de gestión multiescuela y luego multidisciplina ([ADR-004](adr/0004-plataforma-multidisciplina.md)).
