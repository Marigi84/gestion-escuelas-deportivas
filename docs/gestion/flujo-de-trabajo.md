# Flujo de trabajo

## Herramientas

- **GitHub Projects:** [tablero del producto](https://github.com/users/Marigi84/projects/5) (backlog e iteraciones).
- **Issues:** cada unidad de trabajo, con plantillas por tipo.
- **Pull Requests:** todo cambio entra a `main` mediante PR.
- **Docs-as-code:** documentación en Markdown dentro del repositorio, publicada con MkDocs.

## Tablero

| Columna | Significado |
|---|---|
| Backlog | Trabajo identificado, sin priorizar |
| Listo para empezar | Definido y priorizado |
| En curso | En desarrollo |
| En revisión | PR abierto |
| Hecho | Fusionado a `main` |

### Campos

- **Tipo:** Épica, Historia, Tarea, Documentación, Bug.
- **Prioridad:** Alta, Media, Baja.
- **Estimación:** puntos (1, 2, 3, 5, 8).
- **Iteración:** sprints de 2 semanas.
- **Módulo:** escuelas, usuarios, alumnos, tutores, preinscripciones, cuotas, pagos, recibos, reportes, portal, sitio-publico, offline, docs.

## Ramas y commits

Ver [CONTRIBUTING.md](https://github.com/Marigi84/gestion-escuelas-deportivas/blob/main/CONTRIBUTING.md).

## Definición de terminado

- El issue tiene criterios de aceptación cumplidos.
- La documentación afectada está actualizada.
- El PR fue revisado y los checks pasan.
